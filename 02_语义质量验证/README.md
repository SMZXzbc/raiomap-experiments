# 02 语义质量验证

分别检查旧13字段的场景区分度、MLP表示，以及建筑/植被覆盖率在整图和8×8网格上的准确性。

29母图中，13字段有7项恒定或缺失，类别向量及两组MLP表示均只有19种。Astra整图建筑/植被覆盖率MAE为3.75/3.38个百分点；网格实验共34图，其中29张扩展图的逐格MAE为14.15/13.51个百分点。整图估计和局部网格是不同任务：存在粗粒度与空间信号，局部误差和重复波动仍明显。
