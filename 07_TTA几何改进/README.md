# 07 TTA几何改进

在同城39母图、930配置上，将原图、水平翻转、垂直翻转、180度旋转的高度预测逆变换对齐后平均，再输入原冻结RadioMap网络。

全图高度MAE由3.930m降至3.677m，真建筑区由10.781m降至9.984m，support IoU由0.338升至0.398；RadioMap全图MSE却由0.015546升至0.015682。几何更准没有自动转化为当前冻结网络的全图收益。
