# 01 LLM语义对照

检验全局LLM语义能否改善RadioMap，以及语义条件变化是否影响预测。Fair 29按母图划分为23训练、3验证、3测试；四模型均为seed123、20轮，比较保存权重的统一FP32复评结果。

B0＋LLM在验证/测试上相对B0退化11.42%/1.63%；B4相对B3在验证退化2.64%、测试改善4.42%。真实几何有明显价值，LLM语义的收益依赖评价场景，不能概括为始终有效或始终无效。
