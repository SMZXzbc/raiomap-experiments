# 03 空间传播推理

本组按四个子实验展示：空间语义与传播是否对齐、真实高度是否包含可检测信息、模型能否稳定使用高度，以及格式/感知/定位/传播各层能力。

| 子实验 | 核心问题与结论 | 图片数 |
|---|---|---:|
| [01 Tx条件空间语义](01_Tx条件空间语义/README.md) | 26母图、78 Tx；有弱场景对应，未通过完整Tx特异性标准 | 7 |
| [02 P0三维正对照](02_P0三维正对照/README.md) | 26母图、78 Tx；确定性几何评价能检测正确高度的价值 | 13 |
| [03 P1正确与错误高度](03_P1正确与错误高度/README.md) | 12母图、144份有效回答；模型未稳定从正确高度获益 | 8 |
| [04 分层能力测试](04_分层能力测试/README.md) | 简单格式稳定，感知部分有效，坐标定位低于工具，传播pilot较弱 | 3 |

打开各子实验README即可直接查看全部31张结果图片。P0的几何正对照通过，不等于P1已证明模型稳定利用高度，也不直接代表RadioMap预测有收益。

各批实验的样本与条件不同，不能合并统计；多Tx、网格和重复回答不增加独立场景数。历史接口返回的模型字段不能独立核验第三方上游模型身份。
